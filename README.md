# پیامک سفارشات ووکامرس

افزونه مدیریت پیامک وضعیت سفارش‌های ووکامرس با پنل فارسی و مینیمال.

## ویژگی‌ها
- پیامک ثبت سفارش
- پیامک در حال پردازش
- پیامک تکمیل سفارش
- پیامک لغو و ناموفق
- ارسال پیامک هنگام تغییر وضعیت دستی
- ارسال به چند مدیر
- ارسال آزمایشی
- لاگ پیامک‌ها
- آماده Pattern/OTP
- پشتیبانی ساختاری از ملی‌پیامک، فراز SMS، SMS.ir، کاوه‌نگار و قاصدک
