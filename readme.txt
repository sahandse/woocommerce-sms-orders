== Description ==
WooCommerce SMS Orders provides a Persian-first configuration and logging foundation for customer/admin order-status SMS notifications.

== Installation ==
1. Upload the woocommerce-sms-orders folder to /wp-content/plugins/
2. Activate the plugin.
3. Open WooCommerce > پیامک سفارشات.
